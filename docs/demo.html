Independent macOS pre-release, not an official Work Louder product. The four layers select views inside the ChatGPT and Claude desktop apps, not their command-line tools. Dictation uses your separately configured dictation app. The dial press opens search; the pencil key starts a new chat; the hand key sends Escape, whose effect depends on the foreground app. “Hands-free” in the narration means less reaching for the keyboard.
